# Embedded Systems and ARM Assembly

**Category:** Computer Engineering coursework  
**Platform:** ARM Cortex-M / STM32 Nucleo development boards  
**Tools:** C, ARM Assembly, STM32CubeIDE, STM32CubeMX, Renode, debugger and test tooling  
**Status:** Selected coursework completed; additional labs and project material are being organized.

## Overview

Microprocessor coursework focused on programming and debugging ARM Cortex-M microcontrollers. Work has included C and assembly-language exercises, bit manipulation, arithmetic routines, peripheral/toolchain workflows, and verification through debugging and unit tests.

## Representative work

- Implemented and debugged ARM assembly routines for bit-level operations, including bit reversal.
- Worked with 16-bit and n-bit bit-reversal implementations and compared straightforward and optimized approaches.
- Practiced multiword arithmetic and accumulation using ARM instructions, including 64-bit results.
- Built and debugged projects in STM32CubeIDE for STM32 Nucleo hardware.
- Used debugger breakpoints, build output, test results, and technical reports to investigate and document behavior.

## Engineering practices demonstrated

- Reading and reasoning about low-level instruction behavior.
- Register-level data handling and bitwise operations.
- Translating algorithmic requirements into C and assembly.
- Debugging build/runtime issues and interpreting test failures.
- Documenting implementation decisions and verification evidence.
