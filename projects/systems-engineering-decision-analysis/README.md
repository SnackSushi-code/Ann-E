# Systems Engineering Decision Analysis

**Category:** Systems Engineering coursework  
**Team:** Three-person project team  
**Status:** Coursework project; report and analysis completed/in progress as part of the course deliverable.

## Overview

Applied systems-engineering decision methods to a residential decision problem. The project uses a structured comparison process to make alternatives, criteria, tradeoffs, and uncertainty more explicit.

## Methods

- **Trade study:** Define alternatives and compare them against project criteria.
- **Decision analysis:** Organize criteria and evaluate alternatives using a consistent decision framework.
- **Risk and uncertainty analysis:** Identify important uncertainties, assess potential consequences, and communicate how risks affect the decision.

## Engineering practices demonstrated

Requirements and criteria development, structured evaluation, tradeoff analysis, risk identification, team collaboration, and technical reporting.
